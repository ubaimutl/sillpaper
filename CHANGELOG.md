# Changelog

## [0.1.3]

- Fix a crash when changing a heading level with the formatting toolbar.
- Make right-click editor commands work reliably.
- Fix Ctrl-click and the hover button for opening links, and add Open Link to the right-click menu.
- Insert pictures from URLs and keep them available after reopening the document offline.

## [0.1.2]

- Keep the selected text width centered on wide windows and across tabs.
- Show settings in collapsible sections, with Page open by default.
- Improve text rendering in settings inputs and give numeric values more room.

## [0.1.1]

- Add a screenshot to the app store metadata.

## [0.1.0]

- First Sillpaper release for Linux.
- Rich-text editing, Markdown typing shortcuts, Focus Mode, and Typewriter Mode.
- Draft recovery, document tabs, Word and PDF export, and printing.
